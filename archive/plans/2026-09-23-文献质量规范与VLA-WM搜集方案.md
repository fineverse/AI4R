## 3. 规范设计：文献质量分档

### 3.1 第一步——把"假预印本"救出来

很多"预印本"其实已录用，只是 arXiv 版本没更新。核验顺序：

1. arXiv `comments` 字段（常写 "CVPR 2026" / "Accepted to ICLR 2026"）
2. OpenAlex 是否有**非 arXiv 记录**（有则取正式 venue 与引用）
3. 会议官网接收列表

### 3.2 四类信号在两种状态下的可用性

| 信号                          | 已发表                       | 预印本                    |
| --------------------------- | ------------------------- | ---------------------- |
| venue / CCF 评级              | ✅ 查 `shared/ccf/` + 领域白名单 | ❌ 缺失                   |
| 引用数                         | ✅ 按标题取正式版记录               | ⚠️ **无效**（<12 个月）      |
| 同行采纳（被顶会综述详细讨论 / 被同期工作直接对比） | ✅                         | ✅ **最有用**，比引用早 6–12 个月 |
| 团队/作者（OpenAlex 查近 3 年顶会数）   | ✅                         | ✅ 唯一可用先验               |

**引用数只作 >2 年工作的分水岭。**

### 3.3 分档（不给黑箱分数，给可复核依据）

| 档      | 判据                                               | 处理                 |
| ------ | ------------------------------------------------ | ------------------ |
| **T1** | 已发表，venue 在 CCF 或领域白名单                           | 入选，标注评级            |
| **T2** | 预印本但**核实到已录用**                                   | 等同 T1              |
| **T3** | 预印本，被 2025–2026 顶会/顶刊综述**详细讨论**，或被同期顶会工作**直接对比** | 可作代表工作             |
| **T4** | 预印本，已知强团队 **且**（有官方代码 **或** 方法明显独特）              | 入选，标注"仅预印本"        |
| **T5** | 其余                                               | **不收录**，最多进"边界外清单" |

**T4 必须"团队 +（代码 或 独特性）"，不能只看团队**——否则是纯光环效应。

**区分"详细讨论"与"列一行"**：综述有覆盖导向动机，只在表里列一行不算 T3。

### 3.4 表结构（每个论文表新增一列）

```
| 编号 | 论文 | 年份 | venue / CCF | 引用 | 生成机制或输出 | 质量依据（T 档 + 具体信号） |
```

`质量依据` 写**可复核的事实**，不写分数，例如：

* `T1：AAAI'26（CCF-A）`

* `T3：被 VLA4AD 综述 §4.2 详细讨论；仅预印本`

* `T4：团队为 Wayve；有官方代码；仅预印本`
