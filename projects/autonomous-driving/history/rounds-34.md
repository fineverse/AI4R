# 第三十四轮（小方向 README 的必写节：模板声称 2/6，实测对象侧最薄，2026-09-24）

**动因**：`templates.md` 里那份「小方向 README」模板，第二十八轮是**按 AD 侧两个小方向的实况**写的，并在注里声称"实际用产出状态、实际还多出为什么关注与已知线索两节"。本轮做结构侦察时发现：**这个声称只有 2/6 成立**。

## 1. 侦察结果

| 小方向 README | `本小方向的文件` | `要回答的问题` | `边界` | `产出状态` |
|---|---|---|---|---|
| AD `topics/vla` | ✓ | ✓ | ✓ | ✓ |
| AD `topics/world-model` | ✓ | ✓ | ✓ | ✓ |
| **AD `topics/diffusion-planner`**（**研究对象**） | ✓ | ✗ | ✓ | ✗（用的是"证据边界"） |
| 具身 `topics/diffusion-policy` | ✓ | ✗ | ✓ | ✗（用的是"产出约定"） |
| 具身 `topics/vla` | ✗ | ✓ | ✗ | ✗（用的是"产出约定"） |
| 具身 `topics/world-model` | ✗ | ✓ | ✗ | ✗（用的是"产出约定"） |

**最刺眼的一条**：**`diffusion-planner` 是本项目唯一要产出成果的方向，它的 README 却是 6 个里最薄的**——缺"为什么关注 / 要回答的问题 / 已知线索 → 已升级为正式条目 / 产出状态"四节，读者打开它看不到"这个方向要回答什么"。

另发现**状态字段的口径不齐**：AD 侧两个写了"在表 N 篇 / 全部全文级 / N 篇已源码核验"三件，而 `diffusion-planner` 只写"文献调研完成，未立项"、具身侧三个只写"全部摘要级"。

## 2. 做法

1. **把模板改成可执行的规格**（[ai/templates.md](../../../ai/templates.md) §小方向声明）：**「必写 4 节」**（`本小方向的文件` / `要回答的问题` / `边界` / `产出状态`，**节名固定**）+ **「按需若干」**（`为什么关注`、`已知线索 → 已升级为正式条目`、`与自动驾驶侧同名小方向的区别`、`已掌握的事实（指针）`、`一句话定位`、`三条主线/横切轴` 等）。并写明：**状态字段的"口径三件"若某项不适用，必须写明指向何处，不要硬凑数字**（`diffusion-planner` 的逐篇证据状态参差，正属此类——以论文表末列为准）。
2. **补齐 6 个 README**：
   - **`diffusion-planner`（重点）**：新增 `为什么关注`（一句话说清"榜上 SOTA 与可复现 SOTA 差 10 分以上就是机会"）、`要回答的问题`（5 问，全部落在已量化的缺口上）、`已知线索 → 已升级为正式条目`（5 行，每行都有落点）、`产出状态`（并入原"证据边界"）；状态字段补上口径（**在表 34 篇 / 代码可用性 34/34 已核 / 逐篇证据状态以论文表末列为准**）。
   - **具身 3 个**：补 `本小方向的文件`（vla / world-model）与 `边界`（3 个），`产出约定` → **`产出状态`**，状态字段补口径（**在表 14 篇 / 已读全文 0 篇 / 已源码核验 0 篇**——具身侧确实还没有全文级）。
   - **具身 `diffusion-policy`**：补 `要回答的问题`（3 问）。
3. **加第七项检查**：`topics/<x>/README.md` 必须含那 4 节，缺即报错。
