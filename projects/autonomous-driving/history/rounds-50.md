# 第五十轮（2026-09-28）· 明确只读任务必须优先走内置工具

**动因**：用户指出工作中经常通过需要授权的命令行查找和读取信息，要求调整为优先使用内置工具。本轮核对后确认规则此前虽写“只读优先”，但未明确工具调用失败或权限受限时的边界，实际还重复使用 shell 做搜索与阅读。

## 规则调整

- 明确 Read / Grep / Glob 的分工：读文件、搜内容、找文件；多文件读取优先批处理。
- 明确禁止命令行承担读取、搜索、列文件与行数/体积统计。
- 命令行限于程序执行、检查脚本、产物生成；调用前说明内置工具不能完成的具体操作，并收窄命令范围。
- 内置工具因权限边界不可用时，不绕道 shell，暂停该项读取并说明阻塞。

## 产出

- [AGENTS.md](../../../AGENTS.md)：加入每次会话入口可见的读取工具优先级。
- [ai/rules.md](../../../ai/rules.md)：加入可执行的只读工具选择规则。

**执行边界**：本轮规则写回使用工作区编辑能力；命令行只用于既有检查脚本与 git 提交。
