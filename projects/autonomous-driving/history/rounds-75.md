# 第七十五轮：建立「重组地图」——结构（血统）× 因果（受控增益）

日期：2026-10-01

## 起因

用户提出一个**方法论判断**：梳理代码之间的**继承关系**与**模块组合关系**，目的是"帮你（AI）看透这些工作的本质、帮你找灵感"，并问"你觉得呢"。讨论后用户选择**建一张正式对照表**。

## 讨论中的判断（本轮真正的方法论产出）

- **继承/组合图给的是"结构透明"，不是"因果透明"**：它能防撞车、保归因合法（只有同源才能把分差归给机制），但**不回答"为什么 work"**——后者常在一个反直觉的受控实验里（OpenVLA-OFT 的"L1 回归 ≈ 扩散"、GoalFlow 同方法差 4.6 分说明口径支配数字）。
- **本质 = 结构 + 因果两层**；本空间两层**都已存在但从未按行对齐**——结构在 `lineage §继承关系` + 三份 `code_traces`，因果在 `sota-plan §7–§9` + `judgments` + `transfer §1`。
- **图上的空白 ≠ 真空**：同源却未同台比过只是**假设**，必须落最小验证。
- **只按零件图找灵感 → 只会得到"重组式创新"**，而本项目实证是：四条机制轴受控收益 **+3.7 ~ +6.7 同阶**，没有一轴远大于其他；真正的差距在**不在零件图里**的东西（评价口径 / 监督信号 / 约束位置）。
- **这张图对 AI 的价值 > 对人类**：论文**系统性隐藏继承关系**（都自称 novel，基于谁只在 README 致谢 / 团队 / 目录结构里露馅），人类研究者靠**社区记忆**补，而 AI 没有社区记忆 → 落盘的图是**外化的先验**、也是 AI 的记忆。
