## 为什么关注

它是本项目**唯一要产出成果**的方向，而 2025–2026 的困难基准（NAVSIM v2 **navhard**）暴露出一个可被直接攻击的缺口：**榜上 SOTA 与可复现 SOTA 之间有 10 分以上**——前二（55.5 / 54.6）都没有代码，而"有代码的纯扩散规划器"门槛只有 **45.0**（[sota-plan.md §1](../../ideas/sota-plan.md)）。**⚠ 第三十六轮更正**：**45.0（DiffVLA）已不成立**——其**发布代码里没有论文那个扩散头**（README §5 自述换成自研 Transformer 头 + EPDM 子指标 reward loss）→ **在"发布代码"这个口径下，"有代码的纯扩散规划器"为空**；可复现的纯扩散起点改为 **DiffusionDrive 24.2**（见 [sota-plan.md §7.6](../../ideas/sota-plan.md)）。**这个缺口就是本项目的机会**。

## 要回答的问题

1. **生成机制**：换生成器（回归 → 扩散 / 流匹配）的**受控**收益有多大？目前只有 SpanVLA 一处干净对照（**+5.2 PDMS**）。
2. **选优机制**：为什么 scorer 的量级（**≈ +20**）远大于机制本身（+3.7 ~ +6.7）？能否在**推理期不依赖 GT** 也选对？（现有三种选优实现**都在选择环节用 GT**）**⚠ 第四十一至四十三轮把这一问收窄了**：那个 +20 有**三个成立条件**（见 [sota-plan.md §7.2](../../ideas/sota-plan.md)），**20 锚点池拿不到**；而真正可测的量是"**选优损失**"——`PDMS@1` 就是**池子天花板**（DiffusionDrive 丢 **5.4**、DDV2 丢 **3.7**），navhard 上的**地板 gap 已有三个已发表实例**（`C−F ≥ 11.1–20.9`）。→ **要回答的是"把选优损失压下来"，且区分点必须在"监督信号"（在线可得 vs 离线 GT 打分）上**（[sota-plan.md §8.4 / §9.6](../../ideas/sota-plan.md)）。
3. **约束注入**：能否同时做到**实时（≥10 Hz）与硬约束**？现有工作两者不可兼得（PC-Diffuser 约 2 fps、45–59 FPS 的方案没有硬约束）。
4. **收益来源拆解**：世界模型 / 条件 / 生成机制各自 +3 ~ +7，但**没有人做过"把其中两项的收益拆开"的受控实验**。
5. **可复现性**：这个子方向的公开结果有多少可复现？（GuideFlow 自报 43.0 与社区口径 27.1 差 **15.9 分**，且 43.0 不可从发布代码复现）

## 边界

- **纳入**：把生成过程（扩散 / 流匹配 / 扩散桥）用在**规划输出**（轨迹、轨迹集合、控制量序列）上的工作。
- **不纳入**：仅用扩散做场景生成、感知、轨迹预测的工作。

## 三条主线（按生成机制）

| 主线 | 代表 | 起点先验 | 步数 |
|---|---|---|---|
| 截断扩散 + 锚点 | DiffusionDrive、DiffusionDriveV2、AnchDrive、DriveAnchor | 锚点高斯 / 轨迹词表 | 2 步 |
| 纯噪声 + 引导 | Diffusion Planner（nuPlan 闭环） | 纯高斯 | 多步 + DPM-Solver |
| 流匹配 / 一步生成 | GoalFlow、MeanFuser、WAM-Flow、FlowDrive | 纯高斯 / 高斯混合噪声 / 离散 token | 1–5 步 |

## 三条横切轴（按创新位置，比按模型分更有用）

1. **约束注入位置**：事后优化 → 软奖励（RL）→ 生成内软引导 → 去噪内硬约束 + 证书 → 结构层。
2. **条件来源**：场景 BEV/矢量化 → 目标点 → 语言推理 → 未来潜状态。
3. **选优机制**：评分器 / 模式选择器，越来越关键，也逐渐成为瓶颈。
