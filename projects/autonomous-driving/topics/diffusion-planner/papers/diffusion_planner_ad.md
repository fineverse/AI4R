## 证据边界

- 标注 `全文` 的条目由子代理抓取 arXiv HTML 或 PDF（`pdftotext -layout`）逐节/逐表提取。**DP-A21/A12/A22/A18 与 DP-E08 的关键论断已由本线程下载 PDF 并 grep 复核**；DP-A02/A08/A14/A16/A31 的表格数值亦经 PDF 核对。
- 除 DP-A02 外，本表所有结果数字均为**论文自述**，未经本地复现；不同论文的"对齐 backbone""输入权限"不一致，PDMS/EPDMS 不可直接横比（具体反例：GoalFlow 自报 90.3，MeanFuser 表中记为 85.7；DiffusionDrive 自报 88.1，BridgeDrive 复现 87.6）。
- **⚠⚠ 第三十八 / 三十九轮追加两条口径警告（2026-09-24）**：① **v2 的 `EPDMS` 有两套官方实现**——`EPDMS*`（2025-09-29 人-行为过滤修复**之前**）/ `EPDMS`（之后），**同一方法差 2.0–5.2 分**，而**本表多数行不声明用哪套** → **v2 EPDMS 一律按"口径未声明"读**；② **EC（extended comfort）不进 EPDMS**——本地 devkit 把它 mask 掉（配置里的权重 2.0 是死权重），**实际加权和只有 `{EP, TTC, LK, HC}` 四项**。详见 [benchmarks.md §2.3 / §2.9 / §2.10](../../../direction/benchmarks.md)。
- **约束强度的判定口径**（本表用词）：`硬约束` = 有 QP/投影求解 + 可行性证书（DP-A21、DP-E08）；`软引导` = 可微能量/梯度项，无证书（DP-A12、DP-A18、DP-A01）；`软奖励` = 通过 RL 奖励影响策略（DP-A16、DP-A03、DP-A05）。
- 引用数口径见下方「影响力快照」节：OpenAlex 须按**标题**取正式版记录（arXiv DOI 存根记录一律 0 引用）；PMLR/ICML 类无 DOI 论文被低估，**引用数不用于排序**。
- 官方代码快照见 [code/repositories.md](../../../code/repositories.md)：**37/37 已获取**（**第三十六轮更正：原记 36/36**，是第二十一轮新增 `OpenDriveVLA` 之前的旧数；权威计数见 [state.md](../../../state.md)），**仅克隆，未安装、未运行**。
